\subsubsection{收敛特点}

\textbf{Usable Ace在Player sum < 11时价值函数完全为0：}玩家不可能到达Player sum < 11且Usable Ace的状态，因此这部分状态的价值函数从未更新。

\textbf{No Usable Ace在Player sum = 11处出现明显尖峰：}当玩家点数为11且没有Usable Ace时，这是一个关键决策点。在此之前，要牌不会导致爆牌，并且总和越接近21越有可能获胜，因此价值函数逐渐递增；在11以后，要牌有较高风险（抽到10或以上就会爆牌），但停牌的点数又相对较低，致使价值函数陡然下降。由于这个状态的决策复杂性和风险性，其价值估计会表现出较大的波动和相对较高的值，在3D图中形成尖峰。


\subsubsection{方差来源}

价值函数估计中的方差主要来自：(1) $\epsilon$-greedy探索导致的随机动作选择；(2) 环境发牌的随机性；(3) Monte Carlo方法的有限采样。

\subsubsection{学习曲线对比}

该图展示了以下重要现象：

\textbf{1. Mean Value对比——Every-visit初期更低的原因：}

对于\textbf{Usable Ace}情况，前期Every-visit MC的mean value function显著低于First-visit MC（而方差更小），并逐渐追平到同一收敛值。这一现象的深层原因是：

\begin{itemize}
    \item 当策略尚未成熟时，大多数episode都会以失败告终（输掉游戏），因此返回的累积奖励多为负值。
    \item 在Usable Ace的episode中，由于Ace的灵活性，某些状态可能会被多次访问（例如玩家在持有Ace的情况下反复要牌）。First-visit MC只在首次访问时更新一次，而Every-visit MC会在每次访问时都进行更新。
    \item 这意味着Every-visit MC对同一状态的更新次数更多，相当于使用了更大的“有效学习率”。
    \item 在训练初期，这种“更大的学习率”会使得负面结果（失败）更快地反映到价值估计中，导致mean value function下降更快。
    \item 随着策略逐渐成熟，成功率提高，两种方法最终收敛到相同的最优价值。
\end{itemize}

对于No Usable Ace情况，两者的mean value function几乎完全重合，这是因为在No Usable Ace情况下一组$(s,a)$不可能在同一回合中到达两次（因为点数只能增加不能减少），Every-visit实际等价于First-visit。

\textbf{2. 标准差分析：}在No Usable Ace情况下，标准差在$5\times10^5$轮时已完全趋于稳定（约0.48），说明value function estimates已基本收敛，此时剩余方差主要来自不同状态真实价值的结构性差异，而非Monte Carlo估计噪声。而Usable Ace的标准差仍在下降（在0.4以下），可见由于Ace导致的问题复杂度、随机性和建模难度升高，No Usable Ace比Usable Ace收敛更慢。

总体而言，Every-visit MC在训练初期（前10,000轮左右）的平均价值和最大价值变化更快，表现出更激进的学习特征。这是因为Every-visit MC在每次访问状态时都会更新价值函数，利用了更多的信息。而First-visit MC仅在首次访问状态时进行更新，信息利用较少，学习过程更为保守。

\subsubsection{稳定性分析}

Every-visit MC和First-visit MC在Blackjack环境中表现出的差异并不显著。但仔细观察可以发现，在训练后期（200,000轮之后），First-visit MC的Mean Change指标（价值函数变化幅度）略小于Every-visit MC，说明First-visit MC在该环境下可能略微更稳定一些。这可能是因为First-visit MC每个回合中对同一状态只更新一次（首次访问），减少了对同一状态的多次更新，从而降低了方差。

\subsubsection{收敛特点：“安全” vs “激进”}

通过对比训练曲线，我们可以观察到两种算法的显著差异：

\paragraph{SARSA：安全策略}
\begin{itemize}
    \item 收敛后的奖励曲线更加稳定，波动较小
    \item 最终学到的策略更加保守，倾向于选择安全路径
    \item 回合长度的众数为 15-17 步，略高于理论最短路径（13步）
    \item 这说明 SARSA 学到的策略会主动避开悬崖边缘，选择绕路的安全策略
\end{itemize}

\paragraph{Q-Learning：激进策略}
\begin{itemize}
    \item 收敛后仍然存在较为明显的波动和噪声
    \item 时常出现尖锐的负奖励峰值，说明智能体偶尔会掉入悬崖
    \item 回合长度的众数约为 13 步，即理论最短路径
    \item 这说明 Q-Learning 学到的策略更加激进，倾向于紧贴悬崖边缘行走以获得最短路径
\end{itemize}

\paragraph{原因分析}

这种差异的根本原因在于两种算法的更新机制不同：

\begin{itemize}
    \item \textbf{SARSA (On-policy)}：在价值估计时考虑了当前策略的实际行为。由于使用 $\epsilon$-greedy 策略进行探索，智能体有一定概率选择随机动作。在靠近悬崖的状态下，如果随机动作导致掉入悬崖（-100奖励），这个风险会被反映到价值估计中。因此，SARSA 对这些危险状态的价值估计会更加保守，最终学到的策略倾向于避开风险，选择远离悬崖的安全路径以获得相对更高的 on-policy 价值估计。
    
    \item \textbf{Q-Learning (Off-policy)}：在价值估计时使用贪心策略（$\max$ 操作），不考虑探索带来的风险。它估计的是在“完美执行最优策略”情况下的价值。因此，Q-Learning 认为紧贴悬崖边缘的路径是最优的（因为步数最少），即使在实际执行中由于 $\epsilon$-greedy 探索可能会掉入悬崖。这种理想化的价值估计导致 Q-Learning 学到的策略更加激进，偏好最短路径，从而在测试时获得更高的预期回报（假设不进行探索）。
\end{itemize}

这个例子很好地展示了 on-policy 和 off-policy 算法在风险敏感环境中的不同行为特征。

\subsection{Double Q-Learning vs Q-Learning}

在Q-Learning与SARSA的对比中，已经提到Q-Learning存在价值高估问题。这是因为在更新时使用 $\max$ 操作，当存在噪声时，$\max$ 操作会倾向于选择被高估的动作价值，从而导致价值函数的系统性高估。

Double Q-Learning 通过维护两个独立的 Q 函数（$Q_1$ 和 $Q_2$）来缓解这个问题：
\begin{itemize}
    \item 随机选择一个 Q 函数（假设为 $Q_1$）
    \item 使用 $Q_1$ 选择动作：$a^* = \arg\max_a Q_1(s',a)$
    \item 使用 $Q_2$ 评估该动作的价值：$Q_1(s,a) \leftarrow Q_1(s,a) + \alpha[r + \gamma Q_2(s',a^*) - Q_1(s,a)]$
\end{itemize}

这样可以避免用同一个 Q 函数既选择又评估动作，从而减轻高估问题。

通过对比实验，我们可以得出以下结论：

\paragraph{稳定性改善}
Double Q-Learning 明显优于 Q-Learning，前者有效缓解了后者在训练后期出现剧烈震荡的问题，训练过程更加稳定。在Cliff Walking环境中，Q-Learning由于价值高估使得策略不稳定，智能体可能选择实际上次优的动作，导致训练曲线波动。

\paragraph{价值高估缓解}
Q-Learning 的平均 Q 值比 Double Q-Learning 高出相当一部分（约50\%），说明 Q-Learning 存在较为严重的价值高估问题。而 Double Q-Learning 通过引入两个独立的 Q 表，将动作选择和动作评估分离，有效减轻了这一问题。

\paragraph{理论验证}
本实验很好地验证了 Double Q-Learning 论文中提出的理论：通过解耦动作选择和价值评估，可以显著降低 Q-Learning 中由于 $\max$ 操作导致的系统性高估。这种改进在实践中具有重要意义，特别是在状态空间较大、噪声较多的环境中。

\chapter{实验原理} \label{chap:theory}

本次实验旨在基于深度强化学习（Deep Reinforcement Learning）解决 $12 \times 12$ 棋盘下的五子棋博弈问题。我们首先简要需要介绍一些强化学习的基本原理以及该实验的原理\footnote{部分由报告的其中一位作者李欣宸的博客中翻译整理，链接：https://xinchengo.github.io/blog-zh/2025/12/29/强化学习记/}。

\section{强化学习基础}
\subsection{马尔可夫决策过程}

\begin{equation}
(\mathcal S, \mathcal A, P, r, \gamma)
\end{equation}

\textbf{蒙特卡洛学习（Monte-Carlo Learning）}是价值函数上的直接 Robbins--Monro 随机逼近，其更新过程如下：

\begin{gather}
G_t \;\triangleq\; \sum_{k=0}^{T-t-1} \gamma^k \, r_{t+k+1},\\
V(s_t) \;\leftarrow\; V(s_t) + \alpha_t\bigl(G_t - V(s_t)\bigr).
\end{gather}

其中 $G_t$ 为从时刻 $t$ 开始到回合终止（终止时刻为 $T$）的折扣回报，$\alpha_t$ 为步长（例如 First/Every-visit MC 常取 $\alpha_t=1/N(s_t)$ 对应样本均值的增量更新）。



\subsection{Bellman 算子}

\textbf{Bellman 期望算子：}

\begin{gather}
(\mathcal T^\pi V)(s)
=
\mathbb E_{a\sim\pi(\cdot\mid s)}
\left[
r(s,a)
+
\gamma
\mathbb E_{s^\prime\sim P(\cdot\mid s,a)} V(s^\prime)
\right],\\
(\mathcal T^\pi Q)(s,a)
=
r(s,a)
+
\gamma
\mathbb E_{s'\sim P(\cdot\mid s,a)}
\mathbb E_{a'\sim\pi(\cdot\mid s')}
Q(s',a').
\end{gather}

\textbf{Bellman 最优算子：}

\begin{gather}
(\mathcal T^\ast V)(s)
=
\max_{a\in\mathcal A}
\left[
r(s,a)
+
\gamma
\mathbb E_{s'\sim P(\cdot\mid s,a)} V(s')
\right],\\
(\mathcal T^\ast Q)(s,a)
=
r(s,a)
+
\gamma
\mathbb E_{s'\sim P(\cdot\mid s,a)}
\max_{a'} Q(s',a').
\end{gather}

当 $\gamma \in (0,1)$ 时，有以下性质成立：

\begin{itemize}
\item $\mathcal T^{\pi}$ 与 $\mathcal T^{\ast}$ 在 $\|\cdot\|_\infty$ 范数下是 $\gamma$-\textbf{收缩映射}
\item 二者均存在唯一的 \textbf{不动点}：
\[
V^{\pi} = \mathcal T^{\pi} V^{\pi}, 
\qquad
V^{\ast} = \mathcal T^{\ast} V^{\ast},
\]
其存在性与唯一性由 Banach 不动点定理保证
\end{itemize}

\subsection{值函数方法简介}

最优值函数满足：

\begin{equation}
V^{\ast} = \mathcal T^{\ast} V^{\ast},
\qquad
\text{或}
\qquad
Q^{\ast} = \mathcal T^{\ast} Q^{\ast}.
\end{equation}

由于 $\mathcal T^\ast$ 是一个收缩映射，迭代过程

\begin{equation}
V_{k+1} = \mathcal T^{\ast} V_k
\end{equation}
是收敛的，这一过程被称为 \textbf{值迭代（Value Iteration）}。
然而，在无模型（model-free）的设定中，状态转移概率 $P$ 下的期望是不可获得的，这就促使我们使用随机逼近方法。

\subsubsection{Q-learning}

Robbins--Monro 随机逼近提供了一种求解“期望形式根方程”的方法。
假设存在函数 $M(\theta)$ 和常数 $\alpha$，使得方程

\begin{equation}
M(\theta) = \alpha
\end{equation}

在 $\theta^\ast$ 处存在唯一解。
我们无法直接观测 $M(\theta)$，但可以获得随机变量 $N(\theta)$ 的样本，其中

\begin{equation}
\mathbb E[N(\theta)] = M(\theta).
\end{equation}

该算法的基本形式为：

\begin{equation}
\theta_{n+1}
\gets
\theta_n - a_n \bigl(N(\theta_n) - \alpha \bigr).
\end{equation}

当步长序列满足

\begin{equation}
\sum_{n=0}^\infty a_n = \infty,
\qquad
\sum_{n=0}^\infty a_n^2 < \infty,
\end{equation}

并且 $N(\theta), M(\theta)$ 具有良好的性质时，$\theta_n$ 保证收敛。

将 Robbins--Monro 随机逼近应用于不动点方程

\begin{equation}
Q^\ast = \mathcal T^\ast Q^\ast,
\end{equation}

即可得到：

\begin{equation}
Q_{t+1}(s_t,a_t)
\gets
Q_t(s_t,a_t)
+
\alpha_t
\Bigl[
r_{t+1}
+
\gamma \max_{a^\prime} Q_t(s_{t+1},a^\prime)
-
Q_t(s_t,a_t)
\Bigr].
\end{equation}

这正是 \textbf{Q-learning} 算法。

\subsubsection{SARSA}

SARSA 是一种 \textbf{on-policy 的时序差分（TD）控制} 方法，它直接学习动作价值函数 $Q(s,a)$。
在采用 $\epsilon$-greedy 等带探索的行为策略 $\pi$ 采样轨迹时，SARSA 的一步更新为：

\begin{equation}
Q(s_t,a_t)
\gets
Q(s_t,a_t)
+
\alpha_t
\Bigl[
r_{t+1}
+
\gamma Q(s_{t+1},a_{t+1})
-
Q(s_t,a_t)
\Bigr].
\end{equation}

其中 $a_{t+1} \sim \pi(\cdot\mid s_{t+1})$ 是 \emph{按当前行为策略实际选择} 的下一步动作，因此 SARSA 会将探索带来的风险一并纳入价值估计。

\subsection{策略方法简介}

\textbf{策略迭代（Policy Iteration）}比值迭代更加微妙，它包含两个基于 Bellman 的步骤：

\begin{gather}
\begin{aligned}
\text{策略评估：}\quad
& V^{\pi_k} = \mathcal T^{\pi_k} V^{\pi_k}, \\
\text{策略改进：}\quad
&
\begin{aligned}
\pi_{k+1}(s)
&=
\arg\max_a
\left[
r(s,a)
+
\gamma
\mathbb E_{s^\prime} V^{\pi_k}(s^\prime)
\right] \\
&=
\arg\max_a Q^{\pi_k}(s,a),
\end{aligned}
\\
\implies\quad
& \mathcal T^{\pi_{k+1}} V^{\pi_k}
=
\mathcal T^{\ast} V^{\pi_k}.
\end{aligned}
\end{gather}

策略方法通常可以分为两类：

\begin{itemize}
\item 模仿 \emph{软化} 或 \emph{近似} 策略迭代的方法，例如 Actor--Critic；
\item 直接优化目标函数 $J(\theta)$ 的方法，即策略梯度方法。
\end{itemize}

当动作空间较大或连续时，策略方法往往更加合适。

当策略不是由显式存储的 $Q(s,a)$ 导出，而是由参数 $\theta$ 参数化时，策略改进步骤可重写为：

\begin{equation}
\pi_{k+1}
\approx
\arg\max_{\pi \in \Pi_\theta}
\mathbb E_{a\sim\pi}
\bigl[
Q^{\pi_k}(s,a)
\bigr].
\end{equation}

在固定评论员（critic）$Q^{\pi_k}$ 的情况下，定义目标函数：

\begin{equation}
J(\theta)
=
\mathbb E_{s\sim d^{\pi_k}}
\mathbb E_{a\sim \pi_\theta(\cdot\mid s)}
\bigl[
Q^{\pi_k}(s,a)
\bigr].
\end{equation}

该目标函数的推导依赖于状态分布 $d^{\pi_k}$，因此在实践中是难以直接处理的。
然而，\textbf{策略梯度定理（Policy Gradient Theorem）} 利用轨迹分布的马尔可夫结构，避免了对状态分布求导：

\begin{equation}
\nabla_\theta J(\theta)
=
\mathbb E
\left[
\nabla_\theta \log \pi_\theta(a\mid s)
\,
Q^{\pi_k}(s,a)
\right].
\end{equation}

这为策略改进提供了一种可行的近似方式。

\subsubsection{Actor-Critic 方法}

由策略梯度定理
\(
\nabla_\theta J(\theta)=\mathbb E\bigl[\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,Q^{\pi}(s_t,a_t)\bigr]
\)
可见，关键在于获得 $Q^{\pi}(s,a)$ 的估计。
\textbf{朴素 Actor-Critic} 的做法是：Actor 用参数 $\theta$ 表示策略 $\pi_\theta(a\mid s)$；Critic 用参数 $\omega$ 近似动作价值函数 $Q_\omega(s,a)\approx Q^{\pi}(s,a)$，并用 TD 方法在线更新该估计。

\paragraph{Critic：用 TD 学习 $Q$}
在按当前策略采样得到 $(s_t,a_t,r_{t+1},s_{t+1},a_{t+1})$ 后，Critic 的一步 TD 误差可写为
\begin{equation}
\delta_t \;\triangleq\; r_{t+1}+\gamma Q_\omega(s_{t+1},a_{t+1})-Q_\omega(s_t,a_t).
\end{equation}
并通过最小化 $\frac{1}{2}\delta_t^2$（或等价的梯度下降）来更新 $\omega$，使 $Q_\omega$ 逐步逼近 $Q^{\pi}$。

\paragraph{Actor：用 $Q$ 作权重的策略梯度}
获得 $Q_\omega$ 后，Actor 的更新可写为
\begin{equation}
\theta \leftarrow \theta + \alpha_\pi\, Q_\omega(s_t,a_t)\,\nabla_\theta\log\pi_\theta(a_t\mid s_t).
\end{equation}
该算法直接对应策略梯度定理，但在实践中往往需要进一步的方差控制（见下节 A2C）。

\subsubsection{A2C 算法}

A2C（Advantage Actor-Critic）在朴素 Actor-Critic 的基础上引入 \textbf{优势函数（Advantage）} 来替代 $Q^{\pi}(s,a)$ 进入策略梯度，从而在不改变期望梯度方向的前提下降低方差、提升稳定性。

\paragraph{优势估计}
优势定义为
\begin{equation}
A^{\pi}(s_t,a_t) \;\triangleq\; Q^{\pi}(s_t,a_t)-V^{\pi}(s_t),
\end{equation}
其中 $V^{\pi}(s)$ 可视为策略梯度中的基线（baseline）。实践中常用 $n$ 步回报（bootstrapping）来构造优势估计：
\begin{gather}
\hat R_t^{(n)} \;\triangleq\; \sum_{k=0}^{n-1}\gamma^k r_{t+k+1} + \gamma^n V_\omega(s_{t+n}),\\
\hat A_t \;\triangleq\; \hat R_t^{(n)} - V_\omega(s_t).
\end{gather}
当 $n=1$ 时，$\hat A_t$ 退化为一步 TD 误差 $\delta_t$；当 $n$ 增大时，回报更接近 Monte-Carlo，偏差减小但方差可能增大。

\paragraph{优化目标（简洁写法）}
Actor 的损失通常写作
\begin{equation}
\mathcal L_{\text{actor}} = -\,\mathbb E\bigl[\log\pi_\theta(a_t\mid s_t)\,\hat A_t\bigr],
\end{equation}
Critic 则拟合 $\hat R_t^{(n)}$：
\begin{equation}
\mathcal L_{\text{critic}} = \frac{1}{2}\,\mathbb E\bigl[\bigl(\hat R_t^{(n)}-V_\omega(s_t)\bigr)^2\bigr].
\end{equation}
为鼓励探索，也常在 $\mathcal L_{\text{actor}}$ 中加入熵正则项 $-\beta\,\mathbb E[\mathcal H(\pi_\theta(\cdot\mid s_t))]$。

\section{二元零和马尔可夫博弈}
五子棋属于二元零和马尔可夫博弈（Binary Zero-Sum Markov Games）。
\begin{itemize}
    \item \textbf{二元零和}：博弈双方黑棋与白棋的利益完全对立，一方的收益即为另一方的损失（$+100$ vs $-100$）。
    \item \textbf{马尔可夫性}：当前棋盘状态 $S_t$ 包含了决策所需的所有历史信息，未来的状态 $S_{t+1}$ 仅取决于当前状态 $S_t$ 和动作 $A_t$。
\end{itemize}

\section{Naive Self Play}
由于缺乏外部专家数据，我们采用朴素自我博弈（Naive Self Play）机制。Agent 在每一轮中分别扮演黑棋和白棋，通过左右互搏来生成训练数据。虽然该方法理论上不保证收敛至纳什均衡，但在实践中能有效探索状态空间并提升策略强度。

\section{Actor-Critic 架构}
模型采用 Actor-Critic 架构以兼顾策略灵活性与训练稳定性：
\begin{itemize}
    \item \textbf{Actor (策略网络 $\pi_\theta$)}：输入状态 $S$，输出动作的概率分布。本次实验重点探索了 Transformer 架构在此处的应用。
    \item \textbf{Critic (价值网络 $V_\omega$)}：输入状态 $S$及动作 $A$，评估当前局面的优劣Q值，计算 TD Error 以指导 Actor 更新。
\end{itemize}

\chapter{约束策略分析}

五子棋规则要求落子必须在空位。模型输出必须满足 \textbf{Constrained Policy}：
1. 非法位置概率为 0。
2. 合法位置概率和为 1。

我们在 \texttt{forward} 中通过 Masking 技术实现：
\begin{lstlisting}[language=Python]
# 1. 创建非法动作掩码 (非0处即有子)
flat_board = input_board.view(batch_size, -1)
illegal_mask = (flat_board != 0)

# 2. Logits 掩码填充
# 使用 -1e9 而非 0，因为 exp(0)=1 会导致概率不为0
logits = logits.masked_fill(illegal_mask, -1e9)

# 3. Softmax 归一化
output_probs = torch.softmax(logits, dim=1)
\end{lstlisting}
这种处理保证了数值稳定性（避免了 $\log(0)$），并严格约束了输出空间。

\section{语法上的问题}

\begin{itemize}
    \item \textbf{张量形状匹配 (Shape Matching)}：
    CNN 输出通常为 $(B, C, H, W)$，而 Transformer 需要 $(B, Seq, Dim)$。在代码中使用了 \texttt{view} 和 \texttt{permute} 进行维度转换，并特别注意了 \texttt{batch\_first=True} 的设置。
    
    \item \textbf{In-place 操作报错}：
    PyTorch 自动微分禁止对叶子节点进行原地修改。在处理 Masking 时，避免了 \texttt{logits[mask] = -inf} 的写法，改用非原地操作 \texttt{masked\_fill}。
    
    \item \textbf{内存泄漏问题}：
    在 \texttt{optimize} 函数返回 loss 时，若不进行 \texttt{.detach()} 操作，会导致计算图持续累积，造成内存泄漏。修复方式为在返回前对损失值调用 \texttt{.detach()}，即 \texttt{return actor\_loss.detach(), critic\_loss.detach()}。
\end{itemize}

\chapter{模型优化与架构创新}
为了突破传统 CNN 在捕捉全局棋型依赖上的局限性，本实验设计了基于 Self-Attention 的 Transformer Actor。

\section{核心代码实现}
在 \texttt{submission.py} 中，\texttt{Actor} 类的关键实现如下：

\begin{lstlisting}[language=Python, caption=Transformer Actor 初始化与前向传播]
class Actor(nn.Module):
    def __init__(self, board_size, model_type="transformer", ...):
        # ... 初始化代码 ...
        self.embed_dim = 64
        # 1. 输入嵌入与位置编码
        self.embedding = nn.Sequential(
            nn.Conv2d(1, self.embed_dim, 3, padding=1), 
            nn.ReLU()
        )
        self.pos_encoder = PositionalEncoding(self.embed_dim)
        
        # 2. Transformer Encoder 堆叠
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=self.embed_dim, nhead=4, batch_first=True
        )
        self.transformer_encoder = nn.TransformerEncoder(encoder_layer, num_layers=2)
        self.output_head = nn.Linear(self.embed_dim, 1)

    def forward(self, x):
        # x shape: (B, 1, 12, 12)
        features = self.embedding(x)
        # Flatten: (B, Embed, N, N) -> (B, N*N, Embed)
        features = features.view(x.size(0), features.size(1), -1).permute(0, 2, 1)
        
        # 加入位置编码并进行 Self-Attention
        features = self.pos_encoder(features)
        features = self.transformer_encoder(features)
        
        # 输出 Logits: (B, N*N)
        logits = self.output_head(features).squeeze(-1)
        
        # ... Masking 处理 (详见下节) ...
        return torch.softmax(logits, dim=1)
\end{lstlisting}

\section{设计动机}
\begin{itemize}
    \item \textbf{全局视野}：传统 CNN 受限于卷积核大小，难以直接关联棋盘远端的棋子。Transformer 利用 Self-Attention 机制，使棋盘上任意两个位置的 Token 都能直接交互，从而捕捉“大局观”。
    \item \textbf{位置编码}：由于 Self-Attention 具有排列不变性，必须引入 Positional Encoding 以保留二维棋盘的空间结构信息。
\end{itemize}

\end{figure}

\textbf{分析：}
\begin{itemize}
    \item \textbf{Baseline CNN}（左图）：熵值在训练初期（约前 1000 episodes）迅速坍塌至 0 附近。这表明模型极快地陷入了确定性策略，虽然收敛速度快，但也意味着它可能过早地放弃了对更优策略的探索（Premature Convergence）。
    \item \textbf{Attention Actor}（中图）：熵值表现出极大的震荡性，且经常出现异常尖峰。这说明单纯在 CNN 后附加 Attention 层可能引入了训练的不稳定性，导致策略分布难以稳定收敛。
    \item \textbf{Transformer Actor}（右图）：熵值呈现出缓慢且平稳的下降趋势，在整个 10000 轮训练中始终维持在 0 以上。这意味着 Transformer 始终保持着一定的探索能力，这种“持续探索”的特性是其最终在胜率上超越 CNN 的关键原因。
\end{itemize}

    \item \textbf{Transformer Actor}：Critic Loss 在训练后期仍保持一定的波动。这是良性的信号：由于 Transformer Actor 持续探索新动作，Critic 不断被迫面对分布外（Out-of-Distribution）的新局面，从而推动价值网络不断修正和学习，最终获得更鲁棒的全局估值能力。
\end{itemize}

\end{itemize}

\subsection{总结}
通过上述三组曲线的对比，我们可以得出结论：在小样本、零和博弈的强化学习任务中，\textbf{避免过早收敛}是提升最终性能的关键。虽然 Baseline CNN 训练曲线看起来平滑、收敛快，但其性能上限被锁死；而 \textbf{Transformer} 凭借其架构天然的低归纳偏置（Inductive Bias），虽然训练过程看起来高熵、高 Loss 波动，但最终学会了更复杂的全局策略，实现了性能的反超。
