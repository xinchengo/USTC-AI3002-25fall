\subsubsection{收敛特点}

\textbf{Usable Ace在Player sum < 11时价值函数完全为0：}玩家不可能到达Player sum < 11且Usable Ace的状态，因此这部分状态的价值函数从未更新。

\textbf{No Usable Ace在Player sum = 11处出现明显尖峰：}当玩家点数为11且没有Usable Ace时，这是一个关键决策点。在此之前，要牌不会导致爆牌，并且总和越接近21越有可能获胜，因此价值函数逐渐递增；在11以后，要牌有较高风险（抽到10或以上就会爆牌），但停牌的点数又相对较低，致使价值函数陡然下降。由于这个状态的决策复杂性和风险性，其价值估计会表现出较大的波动和相对较高的值，在3D图中形成尖峰。


\subsubsection{方差来源}

价值函数估计中的方差主要来自：(1) $\epsilon$-greedy探索导致的随机动作选择；(2) 环境发牌的随机性；(3) Monte Carlo方法的有限采样。

\subsubsection{学习曲线对比}

该图展示了以下重要现象：

\textbf{1. Mean Value对比——Every-visit初期更低的原因：}

对于\textbf{Usable Ace}情况，前期Every-visit MC的mean value function显著低于First-visit MC（而方差更小），并逐渐追平到同一收敛值。这一现象的深层原因是：

\begin{itemize}
    \item 当策略尚未成熟时，大多数episode都会以失败告终（输掉游戏），因此返回的累积奖励多为负值。
    \item 在Usable Ace的episode中，由于Ace的灵活性，某些状态可能会被多次访问（例如玩家在持有Ace的情况下反复要牌）。First-visit MC只在首次访问时更新一次，而Every-visit MC会在每次访问时都进行更新。
    \item 这意味着Every-visit MC对同一状态的更新次数更多，相当于使用了更大的“有效学习率”。
    \item 在训练初期，这种“更大的学习率”会使得负面结果（失败）更快地反映到价值估计中，导致mean value function下降更快。
    \item 随着策略逐渐成熟，成功率提高，两种方法最终收敛到相同的最优价值。
\end{itemize}

对于No Usable Ace情况，两者的mean value function几乎完全重合，这是因为在No Usable Ace情况下一组$(s,a)$不可能在同一回合中到达两次（因为点数只能增加不能减少），Every-visit实际等价于First-visit。

\textbf{2. 标准差分析：}在No Usable Ace情况下，标准差在$5\times10^5$轮时已完全趋于稳定（约0.48），说明value function estimates已基本收敛，此时剩余方差主要来自不同状态真实价值的结构性差异，而非Monte Carlo估计噪声。而Usable Ace的标准差仍在下降（在0.4以下），可见由于Ace导致的问题复杂度、随机性和建模难度升高，No Usable Ace比Usable Ace收敛更慢。

总体而言，Every-visit MC在训练初期（前10,000轮左右）的平均价值和最大价值变化更快，表现出更激进的学习特征。这是因为Every-visit MC在每次访问状态时都会更新价值函数，利用了更多的信息。而First-visit MC仅在首次访问状态时进行更新，信息利用较少，学习过程更为保守。

\subsubsection{稳定性分析}

Every-visit MC和First-visit MC在Blackjack环境中表现出的差异并不显著。但仔细观察可以发现，在训练后期（200,000轮之后），First-visit MC的Mean Change指标（价值函数变化幅度）略小于Every-visit MC，说明First-visit MC在该环境下可能略微更稳定一些。这可能是因为First-visit MC每个回合中对同一状态只更新一次（首次访问），减少了对同一状态的多次更新，从而降低了方差。

\subsubsection{收敛特点：“安全” vs “激进”}

通过对比训练曲线，我们可以观察到两种算法的显著差异：

\paragraph{SARSA：安全策略}
\begin{itemize}
    \item 收敛后的奖励曲线更加稳定，波动较小
    \item 最终学到的策略更加保守，倾向于选择安全路径
    \item 回合长度的众数为 15-17 步，略高于理论最短路径（13步）
    \item 这说明 SARSA 学到的策略会主动避开悬崖边缘，选择绕路的安全策略
\end{itemize}

\paragraph{Q-Learning：激进策略}
\begin{itemize}
    \item 收敛后仍然存在较为明显的波动和噪声
    \item 时常出现尖锐的负奖励峰值，说明智能体偶尔会掉入悬崖
    \item 回合长度的众数约为 13 步，即理论最短路径
    \item 这说明 Q-Learning 学到的策略更加激进，倾向于紧贴悬崖边缘行走以获得最短路径
\end{itemize}

\paragraph{原因分析}

这种差异的根本原因在于两种算法的更新机制不同：

\begin{itemize}
    \item \textbf{SARSA (On-policy)}：在价值估计时考虑了当前策略的实际行为。由于使用 $\epsilon$-greedy 策略进行探索，智能体有一定概率选择随机动作。在靠近悬崖的状态下，如果随机动作导致掉入悬崖（-100奖励），这个风险会被反映到价值估计中。因此，SARSA 对这些危险状态的价值估计会更加保守，最终学到的策略倾向于避开风险，选择远离悬崖的安全路径以获得相对更高的 on-policy 价值估计。
    
    \item \textbf{Q-Learning (Off-policy)}：在价值估计时使用贪心策略（$\max$ 操作），不考虑探索带来的风险。它估计的是在“完美执行最优策略”情况下的价值。因此，Q-Learning 认为紧贴悬崖边缘的路径是最优的（因为步数最少），即使在实际执行中由于 $\epsilon$-greedy 探索可能会掉入悬崖。这种理想化的价值估计导致 Q-Learning 学到的策略更加激进，偏好最短路径，从而在测试时获得更高的预期回报（假设不进行探索）。
\end{itemize}

这个例子很好地展示了 on-policy 和 off-policy 算法在风险敏感环境中的不同行为特征。

\subsection{Double Q-Learning vs Q-Learning}

在Q-Learning与SARSA的对比中，已经提到Q-Learning存在价值高估问题。这是因为在更新时使用 $\max$ 操作，当存在噪声时，$\max$ 操作会倾向于选择被高估的动作价值，从而导致价值函数的系统性高估。

Double Q-Learning 通过维护两个独立的 Q 函数（$Q_1$ 和 $Q_2$）来缓解这个问题：
\begin{itemize}
    \item 随机选择一个 Q 函数（假设为 $Q_1$）
    \item 使用 $Q_1$ 选择动作：$a^* = \arg\max_a Q_1(s',a)$
    \item 使用 $Q_2$ 评估该动作的价值：$Q_1(s,a) \leftarrow Q_1(s,a) + \alpha[r + \gamma Q_2(s',a^*) - Q_1(s,a)]$
\end{itemize}

这样可以避免用同一个 Q 函数既选择又评估动作，从而减轻高估问题。

通过对比实验，我们可以得出以下结论：

\paragraph{稳定性改善}
Double Q-Learning 明显优于 Q-Learning，前者有效缓解了后者在训练后期出现剧烈震荡的问题，训练过程更加稳定。在Cliff Walking环境中，Q-Learning由于价值高估使得策略不稳定，智能体可能选择实际上次优的动作，导致训练曲线波动。

\paragraph{价值高估缓解}
Q-Learning 的平均 Q 值比 Double Q-Learning 高出相当一部分（约50\%），说明 Q-Learning 存在较为严重的价值高估问题。而 Double Q-Learning 通过引入两个独立的 Q 表，将动作选择和动作评估分离，有效减轻了这一问题。

\paragraph{理论验证}
本实验很好地验证了 Double Q-Learning 论文中提出的理论：通过解耦动作选择和价值评估，可以显著降低 Q-Learning 中由于 $\max$ 操作导致的系统性高估。这种改进在实践中具有重要意义，特别是在状态空间较大、噪声较多的环境中。

\chapter{实验原理} \label{chap:theory}

本次实验旨在基于深度强化学习（Deep Reinforcement Learning）解决 $12 \times 12$ 棋盘下的五子棋博弈问题。我们首先简要需要介绍一些强化学习的基本原理以及该实验的原理\footnote{部分由报告的其中一位作者李欣宸的博客中翻译整理，链接：https://xinchengo.github.io/blog-zh/2025/12/29/强化学习记/}。

\section{强化学习基础}
\subsection{马尔可夫决策过程}

\begin{equation}
(\mathcal S, \mathcal A, P, r, \gamma)
\end{equation}

\textbf{蒙特卡洛学习（Monte-Carlo Learning）}是价值函数上的直接 Robbins--Monro 随机逼近，其更新过程如下：

\begin{gather}
G_t \;\triangleq\; \sum_{k=0}^{T-t-1} \gamma^k \, r_{t+k+1},\\
V(s_t) \;\leftarrow\; V(s_t) + \alpha_t\bigl(G_t - V(s_t)\bigr).
\end{gather}

其中 $G_t$ 为从时刻 $t$ 开始到回合终止（终止时刻为 $T$）的折扣回报，$\alpha_t$ 为步长（例如 First/Every-visit MC 常取 $\alpha_t=1/N(s_t)$ 对应样本均值的增量更新）。



\subsection{Bellman 算子}

\textbf{Bellman 期望算子：}

\begin{gather}
(\mathcal T^\pi V)(s)
=
\mathbb E_{a\sim\pi(\cdot\mid s)}
\left[
r(s,a)
+
\gamma
\mathbb E_{s^\prime\sim P(\cdot\mid s,a)} V(s^\prime)
\right],\\
(\mathcal T^\pi Q)(s,a)
=
r(s,a)
+
\gamma
\mathbb E_{s'\sim P(\cdot\mid s,a)}
\mathbb E_{a'\sim\pi(\cdot\mid s')}
Q(s',a').
\end{gather}

\textbf{Bellman 最优算子：}

\begin{gather}
(\mathcal T^\ast V)(s)
=
\max_{a\in\mathcal A}
\left[
r(s,a)
+
\gamma
\mathbb E_{s'\sim P(\cdot\mid s,a)} V(s')
\right],\\
(\mathcal T^\ast Q)(s,a)
=
r(s,a)
+
\gamma
\mathbb E_{s'\sim P(\cdot\mid s,a)}
\max_{a'} Q(s',a').
\end{gather}

当 $\gamma \in (0,1)$ 时，有以下性质成立：

\begin{itemize}
\item $\mathcal T^{\pi}$ 与 $\mathcal T^{\ast}$ 在 $\|\cdot\|_\infty$ 范数下是 $\gamma$-\textbf{收缩映射}
\item 二者均存在唯一的 \textbf{不动点}：
\[
V^{\pi} = \mathcal T^{\pi} V^{\pi}, 
\qquad
V^{\ast} = \mathcal T^{\ast} V^{\ast},
\]
其存在性与唯一性由 Banach 不动点定理保证
\end{itemize}

\subsection{值函数方法简介}

最优值函数满足：

\begin{equation}
V^{\ast} = \mathcal T^{\ast} V^{\ast},
\qquad
\text{或}
\qquad
Q^{\ast} = \mathcal T^{\ast} Q^{\ast}.
\end{equation}

由于 $\mathcal T^\ast$ 是一个收缩映射，迭代过程

\begin{equation}
V_{k+1} = \mathcal T^{\ast} V_k
\end{equation}
是收敛的，这一过程被称为 \textbf{值迭代（Value Iteration）}。
然而，在无模型（model-free）的设定中，状态转移概率 $P$ 下的期望是不可获得的，这就促使我们使用随机逼近方法。

\subsubsection{Q-learning}

Robbins--Monro 随机逼近提供了一种求解“期望形式根方程”的方法。
假设存在函数 $M(\theta)$ 和常数 $\alpha$，使得方程

\begin{equation}
M(\theta) = \alpha
\end{equation}

在 $\theta^\ast$ 处存在唯一解。
我们无法直接观测 $M(\theta)$，但可以获得随机变量 $N(\theta)$ 的样本，其中

\begin{equation}
\mathbb E[N(\theta)] = M(\theta).
\end{equation}

该算法的基本形式为：

\begin{equation}
\theta_{n+1}
\gets
\theta_n - a_n \bigl(N(\theta_n) - \alpha \bigr).
\end{equation}

当步长序列满足

\begin{equation}
\sum_{n=0}^\infty a_n = \infty,
\qquad
\sum_{n=0}^\infty a_n^2 < \infty,
\end{equation}

并且 $N(\theta), M(\theta)$ 具有良好的性质时，$\theta_n$ 保证收敛。

将 Robbins--Monro 随机逼近应用于不动点方程

\begin{equation}
Q^\ast = \mathcal T^\ast Q^\ast,
\end{equation}

即可得到：

\begin{equation}
Q_{t+1}(s_t,a_t)
\gets
Q_t(s_t,a_t)
+
\alpha_t
\Bigl[
r_{t+1}
+
\gamma \max_{a^\prime} Q_t(s_{t+1},a^\prime)
-
Q_t(s_t,a_t)
\Bigr].
\end{equation}

这正是 \textbf{Q-learning} 算法。

\subsubsection{SARSA}

SARSA 是一种 \textbf{on-policy 的时序差分（TD）控制} 方法，它直接学习动作价值函数 $Q(s,a)$。
在采用 $\epsilon$-greedy 等带探索的行为策略 $\pi$ 采样轨迹时，SARSA 的一步更新为：

\begin{equation}
Q(s_t,a_t)
\gets
Q(s_t,a_t)
+
\alpha_t
\Bigl[
r_{t+1}
+
\gamma Q(s_{t+1},a_{t+1})
-
Q(s_t,a_t)
\Bigr].
\end{equation}

其中 $a_{t+1} \sim \pi(\cdot\mid s_{t+1})$ 是 \emph{按当前行为策略实际选择} 的下一步动作，因此 SARSA 会将探索带来的风险一并纳入价值估计。

\subsection{策略方法简介}

\textbf{策略迭代（Policy Iteration）}比值迭代更加微妙，它包含两个基于 Bellman 的步骤：

\begin{gather}
\begin{aligned}
\text{策略评估：}\quad
& V^{\pi_k} = \mathcal T^{\pi_k} V^{\pi_k}, \\
\text{策略改进：}\quad
&
\begin{aligned}
\pi_{k+1}(s)
&=
\arg\max_a
\left[
r(s,a)
+
\gamma
\mathbb E_{s^\prime} V^{\pi_k}(s^\prime)
\right] \\
&=
\arg\max_a Q^{\pi_k}(s,a),
\end{aligned}
\\
\implies\quad
& \mathcal T^{\pi_{k+1}} V^{\pi_k}
=
\mathcal T^{\ast} V^{\pi_k}.
\end{aligned}
\end{gather}

策略方法通常可以分为两类：

\begin{itemize}
\item 模仿 \emph{软化} 或 \emph{近似} 策略迭代的方法，例如 Actor--Critic；
\item 直接优化目标函数 $J(\theta)$ 的方法，即策略梯度方法。
\end{itemize}

当动作空间较大或连续时，策略方法往往更加合适。

当策略不是由显式存储的 $Q(s,a)$ 导出，而是由参数 $\theta$ 参数化时，策略改进步骤可重写为：

\begin{equation}
\pi_{k+1}
\approx
\arg\max_{\pi \in \Pi_\theta}
\mathbb E_{a\sim\pi}
\bigl[
Q^{\pi_k}(s,a)
\bigr].
\end{equation}

在固定评论员（critic）$Q^{\pi_k}$ 的情况下，定义目标函数：

\begin{equation}
J(\theta)
=
\mathbb E_{s\sim d^{\pi_k}}
\mathbb E_{a\sim \pi_\theta(\cdot\mid s)}
\bigl[
Q^{\pi_k}(s,a)
\bigr].
\end{equation}

该目标函数的推导依赖于状态分布 $d^{\pi_k}$，因此在实践中是难以直接处理的。
然而，\textbf{策略梯度定理（Policy Gradient Theorem）} 利用轨迹分布的马尔可夫结构，避免了对状态分布求导：

\begin{equation}
\nabla_\theta J(\theta)
=
\mathbb E
\left[
\nabla_\theta \log \pi_\theta(a\mid s)
\,
Q^{\pi_k}(s,a)
\right].
\end{equation}

这为策略改进提供了一种可行的近似方式。

\subsubsection{Actor-Critic 方法}

由策略梯度定理
\(
\nabla_\theta J(\theta)=\mathbb E\bigl[\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,Q^{\pi}(s_t,a_t)\bigr]
\)
可见，关键在于获得 $Q^{\pi}(s,a)$ 的估计。
\textbf{朴素 Actor-Critic} 的做法是：Actor 用参数 $\theta$ 表示策略 $\pi_\theta(a\mid s)$；Critic 用参数 $\omega$ 近似动作价值函数 $Q_\omega(s,a)\approx Q^{\pi}(s,a)$，并用 TD 方法在线更新该估计。

\paragraph{Critic：用 TD 学习 $Q$}
在按当前策略采样得到 $(s_t,a_t,r_{t+1},s_{t+1},a_{t+1})$ 后，Critic 的一步 TD 误差可写为
\begin{equation}
\delta_t \;\triangleq\; r_{t+1}+\gamma Q_\omega(s_{t+1},a_{t+1})-Q_\omega(s_t,a_t).
\end{equation}
并通过最小化 $\frac{1}{2}\delta_t^2$（或等价的梯度下降）来更新 $\omega$，使 $Q_\omega$ 逐步逼近 $Q^{\pi}$。

\paragraph{Actor：用 $Q$ 作权重的策略梯度}
获得 $Q_\omega$ 后，Actor 的更新可写为
\begin{equation}
\theta \leftarrow \theta + \alpha_\pi\, Q_\omega(s_t,a_t)\,\nabla_\theta\log\pi_\theta(a_t\mid s_t).
\end{equation}
该算法直接对应策略梯度定理，但在实践中往往需要进一步的方差控制（见下节 A2C）。

\subsubsection{A2C 算法}

A2C（Advantage Actor-Critic）在朴素 Actor-Critic 的基础上引入 \textbf{优势函数（Advantage）} 来替代 $Q^{\pi}(s,a)$ 进入策略梯度，从而在不改变期望梯度方向的前提下降低方差、提升稳定性。

\paragraph{优势估计}
优势定义为
\begin{equation}
A^{\pi}(s_t,a_t) \;\triangleq\; Q^{\pi}(s_t,a_t)-V^{\pi}(s_t),
\end{equation}
其中 $V^{\pi}(s)$ 可视为策略梯度中的基线（baseline）。实践中常用 $n$ 步回报（bootstrapping）来构造优势估计：
\begin{gather}
\hat R_t^{(n)} \;\triangleq\; \sum_{k=0}^{n-1}\gamma^k r_{t+k+1} + \gamma^n V_\omega(s_{t+n}),\\
\hat A_t \;\triangleq\; \hat R_t^{(n)} - V_\omega(s_t).
\end{gather}
当 $n=1$ 时，$\hat A_t$ 退化为一步 TD 误差 $\delta_t$；当 $n$ 增大时，回报更接近 Monte-Carlo，偏差减小但方差可能增大。

\paragraph{优化目标（简洁写法）}
Actor 的损失通常写作
\begin{equation}
\mathcal L_{\text{actor}} = -\,\mathbb E\bigl[\log\pi_\theta(a_t\mid s_t)\,\hat A_t\bigr],
\end{equation}
Critic 则拟合 $\hat R_t^{(n)}$：
\begin{equation}
\mathcal L_{\text{critic}} = \frac{1}{2}\,\mathbb E\bigl[\bigl(\hat R_t^{(n)}-V_\omega(s_t)\bigr)^2\bigr].
\end{equation}
为鼓励探索，也常在 $\mathcal L_{\text{actor}}$ 中加入熵正则项 $-\beta\,\mathbb E[\mathcal H(\pi_\theta(\cdot\mid s_t))]$。

\section{二元零和马尔可夫博弈}
五子棋属于二元零和马尔可夫博弈（Binary Zero-Sum Markov Games）。
\begin{itemize}
    \item \textbf{二元零和}：博弈双方黑棋与白棋的利益完全对立，一方的收益即为另一方的损失（$+100$ vs $-100$）。
    \item \textbf{马尔可夫性}：当前棋盘状态 $S_t$ 包含了决策所需的所有历史信息，未来的状态 $S_{t+1}$ 仅取决于当前状态 $S_t$ 和动作 $A_t$。
\end{itemize}

\section{Naive Self Play}
由于缺乏外部专家数据，我们采用朴素自我博弈（Naive Self Play）机制。Agent 在每一轮中分别扮演黑棋和白棋，通过左右互搏来生成训练数据。虽然该方法理论上不保证收敛至纳什均衡，但在实践中能有效探索状态空间并提升策略强度。

\section{Actor-Critic 架构}
模型采用 Actor-Critic 架构以兼顾策略灵活性与训练稳定性：
\begin{itemize}
    \item \textbf{Actor (策略网络 $\pi_\theta$)}：输入状态 $S$，输出动作的概率分布。本次实验重点探索了 Transformer 架构在此处的应用。
    \item \textbf{Critic (价值网络 $V_\omega$)}：输入状态 $S$及动作 $A$，评估当前局面的优劣Q值，计算 TD Error 以指导 Actor 更新。
\end{itemize}

\section{Actor 网络设计}

Actor 网络负责生成动作概率分布 $\pi_\theta(a\mid s)$。我们实现了三种主要架构：CNN、Attention 和 Transformer。

\subsection{模型初始化关键代码}

\subsubsection{CNN 架构}

\begin{lstlisting}[language=Python]
# CNN Actor: 堆叠卷积层提取棋盘局部特征
depth = self.extra_specs.get('depth', 4)
channels = self.extra_specs.get('channels', 64)
use_batch_norm = self.extra_specs.get('batch_norm', False)

layers = []
in_channels = 1

for i in range(depth):
    out_channels = channels
    layers.append(nn.Conv2d(in_channels, out_channels, 
                           kernel_size=3, padding=1))
    if use_batch_norm:
        layers.append(nn.BatchNorm2d(out_channels))
    layers.append(nn.ReLU())
    in_channels = out_channels

self.conv_blocks = nn.Sequential(*layers)
flat_features = channels * board_size * board_size
self.fc = nn.Linear(flat_features, board_size * board_size)
\end{lstlisting}

\textbf{设计动机：}
\begin{itemize}
    \item \textbf{局部特征提取}：卷积核能够有效捕获棋盘上的局部棋型（如连子、跳子等）。
    \item \textbf{参数共享}：相同的卷积核在整个棋盘上滑动，减少参数量并增强泛化能力。
    \item \textbf{可调深度与宽度}：通过 \texttt{depth} 和 \texttt{channels} 超参数控制模型容量，平衡表达能力与训练效率。
    \item \textbf{Batch Normalization}：可选的 BN 层稳定训练过程，加速收敛。
\end{itemize}

\subsubsection{Transformer 架构}

\begin{lstlisting}[language=Python]
# Transformer Actor: 全局自注意力机制
embed_dim = self.extra_specs.get('embed_dim', 64)
num_heads = self.extra_specs.get('num_heads', 4)
num_layers = self.extra_specs.get('num_layers', 2)

# Input Embedding: 将棋盘嵌入到高维空间
self.embedding = nn.Sequential(
    nn.Conv2d(1, embed_dim, kernel_size=3, padding=1),
    nn.ReLU()
)

# 位置编码: 为序列注入位置信息
self.pos_encoder = PositionalEncoding(embed_dim, 
                                     max_len=board_size*board_size)

# Transformer Encoder Stack
encoder_layer = nn.TransformerEncoderLayer(
    d_model=embed_dim, 
    nhead=num_heads, 
    batch_first=True
)
self.transformer_encoder = nn.TransformerEncoder(
    encoder_layer, 
    num_layers=num_layers
)

# 输出头: 为每个位置生成 logit
self.output_head = nn.Linear(embed_dim, 1)
\end{lstlisting}

\textbf{设计动机：}
\begin{itemize}
    \item \textbf{全局依赖建模}：Self-Attention 机制允许每个位置直接与棋盘上所有其他位置交互，捕获长距离的战略关联（如双头攻击、威胁与防守）。
    \item \textbf{位置编码}：由于 Transformer 本身不具备位置感知能力，通过正弦位置编码为每个位置注入空间信息。
    \item \textbf{可扩展性}：通过增加 \texttt{num\_layers} 和 \texttt{embed\_dim} 可以显著提升模型的表达能力，适合复杂博弈场景。
\end{itemize}

\subsection{Forward 方法关键代码}

\begin{lstlisting}[language=Python]
def forward(self, x: np.ndarray):
    # 统一输入格式为 (B, 1, N, N)
    input_board = output.clone()
    batch_size = output.size(0)
    
    if self.model_type == "cnn":
        # CNN 前向传播
        out = self.conv_blocks(output)
        out = out.view(out.size(0), -1)  # 展平为 (B, C*N*N)
        logits = self.fc(out)  # 生成 logits: (B, N*N)
    
    elif self.model_type == "transformer":
        # Embedding: (B, 1, N, N) -> (B, Embed, N, N)
        features = self.embedding(output)
        # Flatten to sequence: (B, N*N, Embed)
        features = features.view(batch_size, features.size(1), -1)
                          .permute(0, 2, 1)
        # 位置编码
        features = self.pos_encoder(features)
        # Transformer 编码
        features = self.transformer_encoder(features)
        # 输出: (B, N*N, 1) -> (B, N*N)
        logits = self.output_head(features).squeeze(-1)
    
    # *** 约束策略处理（见下节） ***
    flat_board = input_board.view(batch_size, -1)
    illegal_mask = (flat_board != 0)  # 非空位置为非法
    logits = logits.masked_fill(illegal_mask, -1e9)
    output_probs = torch.softmax(logits, dim=1)
    
    return output_probs
\end{lstlisting}

\section{Critic 网络设计}

Critic 网络估计状态-动作对的 Q 值 $Q_\omega(s, a)$。关键挑战在于如何将动作信息 $a$ 注入到网络中。

\subsection{动作注入策略}

我们实现了三种动作注入方式（\texttt{action\_injection}）：

\begin{enumerate}
    \item \textbf{Early Injection}：将动作作为额外通道拼接到输入棋盘上。
    \item \textbf{Late Injection}：在最后一个卷积层之前将动作 mask 拼接到特征图上。
    \item \textbf{FC Injection}：在全连接层将动作坐标归一化后拼接到展平特征上。
\end{enumerate}

\subsection{Late Injection 关键代码}

\begin{lstlisting}[language=Python]
# Late Injection: 在最后一层卷积前注入动作信息
elif self.action_injection == "late":
    layers_list = list(self.conv_blocks)
    # 找到最后一个 Conv2d 层
    last_conv_idx = -1
    for i in range(len(layers_list) - 1, -1, -1):
        if isinstance(layers_list[i], nn.Conv2d):
            last_conv_idx = i
            break
    
    # 前向传播到倒数第二层
    for i in range(last_conv_idx):
        output = layers_list[i](output)
    
    # 创建动作 mask: (B, 1, N, N)，在动作位置标记为 1
    action_mask = torch.zeros(batch_size, 1, 
                             self.board_size, self.board_size).to(device)
    for j, (ax, ay) in enumerate(action_tensor):
        action_mask[j, 0, int(ax), int(ay)] = 1.0
    
    # 拼接特征与动作 mask
    output = torch.cat([output, action_mask], dim=1)
    
    # 继续最后一层卷积及后续层
    for i in range(last_conv_idx, len(layers_list)):
        output = layers_list[i](output)
\end{lstlisting}

\textbf{设计动机：}
\begin{itemize}
    \item \textbf{特征融合}：在高层特征上注入动作信息，使网络能够结合已提取的棋盘语义特征与具体动作位置，更准确地评估 Q 值。
    \item \textbf{空间定位}：相比把动作作为二维数值特征，将其转换为与棋盘同尺寸的 mask，有助于网络更直观地理解动作在棋盘上的位置关系。
    \item \textbf{适配 Backbone}：该方法适用于 Actor 和 Critic 共享骨架的情况，动作在 Critic 头处进行注入。
\end{itemize}

\subsection{FC Injection 关键代码}

# 全连接层输出所有位置的 Q 值

\begin{itemize}

\chapter{约束策略分析}

五子棋规则要求落子必须在空位。模型输出必须满足 \textbf{Constrained Policy}（约束策略）的两个核心要求：
\begin{enumerate}
    \item \textbf{0 限制（Zero Constraint）}：非法位置（已有棋子的位置）的动作概率必须严格为 0。
    \item \textbf{归一限制（Normalization Constraint）}：所有合法位置的动作概率之和必须为 1。
\end{enumerate}

\section{Forward 部分的约束实现}

我们在 Actor 的 \texttt{forward} 方法中通过 \textbf{Masking + Softmax} 技术优雅地解决了这两个约束：

\begin{lstlisting}[language=Python]
# 保留原始棋盘用于创建掩码
input_board = output.clone()
batch_size = output.size(0)

# ... (模型前向传播，生成 logits) ...

# ========== 约束策略处理 ==========
# 步骤 1: 创建非法动作掩码
# 将棋盘展平为 (B, N*N)，非 0 位置表示已有棋子（非法）
flat_board = input_board.view(batch_size, -1)
illegal_mask = (flat_board != 0)  # (B, N*N) 布尔张量

# 步骤 2: Logits 掩码填充
# 将非法位置的 logit 设为极小值 -1e9
logits = logits.masked_fill(illegal_mask, -1e9)

# 步骤 3: Softmax 归一化
# 自动满足归一化约束，且非法位置概率趋近于 0
output_probs = torch.softmax(logits, dim=1)

return output_probs
\end{lstlisting}

\section{如何解决 0 限制}

\subsection{技术原理}

\textbf{问题：}如何保证非法位置的概率严格为 0？

\textbf{解决方案：}利用 Softmax 函数的数学性质。

Softmax 定义为：
\begin{equation}
p_i = \frac{e^{z_i}}{\sum_{j=1}^{N^2} e^{z_j}},
\end{equation}
其中 $z_i$ 是位置 $i$ 的 logit。

当 $z_i \to -\infty$ 时：
\begin{equation}
p_i = \frac{e^{-\infty}}{\sum_j e^{z_j}} = \frac{0}{\text{正数}} = 0.
\end{equation}

在实践中，我们使用 $-10^9$ 作为"负无穷"的数值近似。此时：
\begin{equation}
e^{-10^9} \approx 10^{-4.3 \times 10^8} \approx 0 \quad (\text{在浮点精度下}).
\end{equation}

\subsection{为什么不直接设为 0？}

\textbf{错误做法：}
\begin{lstlisting}[language=Python]
# 错误！会导致数值问题
logits[illegal_mask] = 0  # In-place 操作还会破坏梯度
output_probs = torch.softmax(logits, dim=1)
\end{lstlisting}

\textbf{问题分析：}
\begin{enumerate}
    \item \textbf{概率非零}：$e^0 = 1$，非法位置的概率为 $\frac{1}{\sum_j e^{z_j}}$，并非 0。
    \item \textbf{梯度破坏}：In-place 操作会导致 PyTorch 自动微分失败。
    \item \textbf{归一化失效}：非法位置"占用"了部分概率质量，导致合法位置概率偏低。
\end{enumerate}

\textbf{正确做法：}使用 \texttt{masked\_fill} 非原地操作，填充极小值：
\begin{lstlisting}[language=Python]
logits = logits.masked_fill(illegal_mask, -1e9)  # 非原地操作
\end{lstlisting}

\section{如何解决归一限制}

\subsection{Softmax 的归一化性质}

Softmax 函数天然满足归一化约束：
\begin{equation}
\sum_{i=1}^{N^2} p_i = \sum_{i=1}^{N^2} \frac{e^{z_i}}{\sum_{j=1}^{N^2} e^{z_j}} = \frac{\sum_{i=1}^{N^2} e^{z_i}}{\sum_{j=1}^{N^2} e^{z_j}} = 1.
\end{equation}

由于非法位置的 $e^{z_i} \approx 0$，实际效果等价于：
\begin{equation}
\sum_{i \in \text{Legal}} p_i \approx 1, \quad p_i = 0 \; (\forall i \in \text{Illegal}).
\end{equation}

\subsection{数值稳定性保证}

PyTorch 的 \texttt{torch.softmax} 实现了数值稳定的版本：
\begin{equation}
p_i = \frac{e^{z_i - z_{\max}}}{\sum_j e^{z_j - z_{\max}}},
\end{equation}
其中 $z_{\max} = \max_j z_j$。这避免了指数运算溢出（当 $z_i$ 很大时 $e^{z_i}$ 会溢出）。

即使非法位置的 logit 为 $-10^9$，由于减去 $z_{\max}$ 后仍然是极小值，不会引起数值问题。

\begin{lstlisting}[language=Python]
# 可行但不优雅的方法
output_probs = torch.softmax(logits, dim=1)
output_probs[illegal_mask] = 0  # 置 0（破坏梯度！）
output_probs = output_probs / output_probs.sum(dim=1, keepdim=True)  # 重归一化
\end{lstlisting}

\textbf{缺点：}
\begin{itemize}
    \item 破坏计算图，导致梯度无法正确传播到非法位置的 logits。
    \item 需要额外的归一化步骤，增加计算开销。
    \item 代码不够优雅，容易出错。
\end{itemize}

\chapter{Bug 修复}

在 \texttt{optimize} 函数中修复了三个关键 Bug：

\begin{enumerate}
    \item \textbf{梯度阻断}：
    原代码 \texttt{targets = rewards + gamma * next\_qs} 导致梯度错误地传导至目标网络。
    \begin{itemize}
        \item \textbf{修复}：添加 \texttt{.detach()}，即 \texttt{targets = rewards + gamma * next\_qs.detach()}。
    \end{itemize}
    
    \item \textbf{Actor 优化缺失}：
    原代码 \texttt{actor\_loss.backward()} 后未执行更新。
    \begin{itemize}
        \item \textbf{修复}：补充 \texttt{self.actor.optimizer.step()}。
    \end{itemize}
    
    \item \textbf{Critic 优化缺失}：
    原代码 \texttt{critic\_loss.backward()} 后未执行更新。
    \begin{itemize}
        \item \textbf{修复}：补充 \texttt{self.critic.optimizer.step()}。
    \end{itemize}
\end{enumerate}

\chapter{其他问题记录}

\section{语法上的问题}

\begin{itemize}
    \item \textbf{张量形状匹配 (Shape Matching)}：
    CNN 输出通常为 $(B, C, H, W)$，而 Transformer 需要 $(B, Seq, Dim)$。在代码中使用了 \texttt{view} 和 \texttt{permute} 进行维度转换，并特别注意了 \texttt{batch\_first=True} 的设置。
    
    \item \textbf{In-place 操作报错}：
    PyTorch 自动微分禁止对叶子节点进行原地修改。在处理 Masking 时，避免了 \texttt{logits[mask] = -inf} 的写法，改用非原地操作 \texttt{masked\_fill}。
    
    \item \textbf{内存泄漏问题}：
    在 \texttt{optimize} 函数返回 loss 时，若不进行 \texttt{.detach()} 操作，会导致计算图持续累积，造成内存泄漏。修复方式为在返回前对损失值调用 \texttt{.detach()}，即 \texttt{return actor\_loss.detach(), critic\_loss.detach()}。
\end{itemize}

\chapter{模型优化与架构创新}
为了突破传统 CNN 在捕捉全局棋型依赖上的局限性，本实验设计了基于 Self-Attention 的 Transformer Actor。

\section{核心代码实现}
在 \texttt{submission.py} 中，\texttt{Actor} 类的关键实现如下：

\begin{lstlisting}[language=Python, caption=Transformer Actor 初始化与前向传播]
class Actor(nn.Module):
    def __init__(self, board_size, model_type="transformer", ...):
        # ... 初始化代码 ...
        self.embed_dim = 64
        # 1. 输入嵌入与位置编码
        self.embedding = nn.Sequential(
            nn.Conv2d(1, self.embed_dim, 3, padding=1), 
            nn.ReLU()
        )
        self.pos_encoder = PositionalEncoding(self.embed_dim)
        
        # 2. Transformer Encoder 堆叠
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=self.embed_dim, nhead=4, batch_first=True
        )
        self.transformer_encoder = nn.TransformerEncoder(encoder_layer, num_layers=2)
        self.output_head = nn.Linear(self.embed_dim, 1)

    def forward(self, x):
        # x shape: (B, 1, 12, 12)
        features = self.embedding(x)
        # Flatten: (B, Embed, N, N) -> (B, N*N, Embed)
        features = features.view(x.size(0), features.size(1), -1).permute(0, 2, 1)
        
        # 加入位置编码并进行 Self-Attention
        features = self.pos_encoder(features)
        features = self.transformer_encoder(features)
        
        # 输出 Logits: (B, N*N)
        logits = self.output_head(features).squeeze(-1)
        
        # ... Masking 处理 (详见下节) ...
        return torch.softmax(logits, dim=1)
\end{lstlisting}

\section{设计动机}
\begin{itemize}
    \item \textbf{全局视野}：传统 CNN 受限于卷积核大小，难以直接关联棋盘远端的棋子。Transformer 利用 Self-Attention 机制，使棋盘上任意两个位置的 Token 都能直接交互，从而捕捉“大局观”。
    \item \textbf{位置编码}：由于 Self-Attention 具有排列不变性，必须引入 Positional Encoding 以保留二维棋盘的空间结构信息。
\end{itemize}

\chapter{思考题}

\section{问题陈述}

若模型权重收敛至 Actor/Critic Loss 最优点，黑白双方策略是否一定达成纳什均衡（Nash Equilibrium）？为什么？

\textbf{结论：}即使模型完全收敛至训练损失的最优点，黑白双方策略也\textbf{不一定}达成纳什均衡。

\section{理论分析}

首先要澄清的一点是，五子棋是一项先手必胜的游戏，其纳什均衡的结果是先手必胜。因此，若双方均为理性玩家，纳什均衡策略应当使得先手方获胜。

但是，由于 Actor 和 Critic 的表达能力有限，即使它们能够达到\textbf{在模型参数空间内}的最优点，也不一定能实现纳什均衡策略。由我们的实验结果可见，模型的表达能力远没有到能够体现五子棋“先手必胜”性质的程度，所以我们接下来的分析均建立在对于“一般二人零和博弈”的前提上。

\subsection{纳什均衡的定义}

在二人零和博弈中，策略对 $(\pi_1^*, \pi_2^*)$ 构成纳什均衡当且仅当：
\begin{equation}
\begin{cases}
\pi_1^* = \arg\max_{\pi_1} V(\pi_1, \pi_2^*), \\
\pi_2^* = \arg\max_{\pi_2} V(\pi_2, \pi_1^*),
\end{cases}
\end{equation}
其中 $V(\pi_i, \pi_j)$ 是玩家 $i$ 在策略组合 $(\pi_i, \pi_j)$ 下的期望收益。

换言之，双方策略必须\textbf{互为最优反应（Best Response）}：给定对手策略，自己无法通过单方面改变策略获得更高收益。

\subsection{Naive Self-Play 的训练目标}

本实验采用的 Naive Self-Play 机制中，Actor-Critic 优化的目标是：
\begin{gather}
\mathcal{L}_{\text{actor}} = -\mathbb{E}_{s,a \sim \pi_\theta}\bigl[\log\pi_\theta(a|s) \cdot Q_\omega(s,a)\bigr], \\
\mathcal{L}_{\text{critic}} = \mathbb{E}\bigl[\bigl(r + \gamma \max_{a'} Q_\omega(s',a') - Q_\omega(s,a)\bigr)^2\bigr].
\end{gather}

这些损失函数衡量的是：
\begin{itemize}
    \item \textbf{Actor}：在当前 Critic 评估下，策略能否选择高价值动作。
    \item \textbf{Critic}：对当前策略生成的轨迹，价值估计是否准确。
\end{itemize}

然而，\textbf{最小化这些损失并不等价于找到纳什均衡}。

在 Self-Play 中，黑白双方共享同一个神经网络参数 $\theta$。训练过程可视为：
\begin{equation}
\theta_{t+1} = \theta_t - \alpha \nabla_\theta \mathcal{L}(\theta_t, \theta_t).
\end{equation}

这里的问题在于：\textbf{对手策略是自己的历史版本，而非固定策略}。当 $\theta$ 更新时，对手策略 $\pi_{\theta_t}$ 也随之变化，导致优化目标不断漂移。即使某一时刻 Loss 达到局部最优，下一步对手策略改变后，这个"最优"就失效了。

Actor-Critic 本质上是基于策略梯度的局部优化方法。即使收敛，也只能保证到达\textbf{局部最优点或鞍点}，而非全局纳什均衡。

\section{实验证据}

我们的实验结果恰好支持了上述理论分析：

\begin{enumerate}
    \item \textbf{性能震荡}：表 \ref{tab:internal_eval} 显示，训练到 9999 轮的模型反而不如 8499 轮模型强。这说明即使 Loss 持续下降，策略强度也可能退化（Forgetting）。
    
    \item \textbf{循环现象}：Transformer Actor 的 Entropy 和 Loss 曲线（图 \ref{fig:entropy_comparison}、\ref{fig:actor_loss_comparison}）有时表现出突然上升到很高，然后再下降的现象，暗示策略可能刚跳出某个局部最优，又陷入另一个局部最优，而不是稳定下降到纳什均衡。
\end{enumerate}

\chapter{课程反馈}

\section{对课程及实验的建议}

关于本学期的《人工智能与机器学习基础》课程，我们认为有以下几点影响上课体验的地方：

\begin{itemize}
    \item \textbf{教学内容与实验内容相关性低}：课程内容涵盖了大量机器学习基础理论和算法，但与实验项目（如三次小实验，一次大实验）的关联性不强；不需要理解各种理论细节就可以完成实验任务。
    \item \textbf{实验完成基本要求太容易，拓展部分缺乏详细说明}：实验项目难度跨度较大，拿基本分（补全所有代码、写好报告）并不难，给分标准也很明确；但是作为一门 4 学分的主课且没有期末考试，同学们\textit{普遍期望挑战更高难度的内容}来提升自己的能力且取得不错的成绩。
    
    目前的实验内容在\textit{实验拓展}的评分标准尚不明确，实验往往要么\textit{缺乏拓展性}（比如 LAB2 的 MNIST 聚类实验，达到实验效果就难以对其进行更加详细的分析）或者\textit{拓展内容过于宽泛}（比如本次 Final-Project 的 gobang 部分，五子棋 AI 的优化空间巨大，导致同学们在试错的过程中过于盲目，付出大量时间但对模型表现收获甚微）。
\end{itemize}

我相信，这门课程设立的初衷是希望同学们能够通过理论学习和动手实践，掌握机器学习的\textit{基本方法}并具备一定的\textit{研究能力}；因此，实验应当具有一定的\textit{学术性}，报告的要求也应当体现出 AI 领域的\textit{科研范式}。

因此我们对课程和实验提出如下的建议：

\begin{itemize}
    \item \textbf{「任务导向」向「目标导向」的转化}：传统的“补全代码”任务很容易借由 AI 工具速通，给分模式也太过单一；建议将实验任务设计为“实现某个目标”，以下是一些示例：
    \begin{itemize}
        \item 助教给出一个强模型，同学们需要完成 Ablation Study，修改代码（比如增加一些 \verb|argparse| 参数）自行设计一些对比实验，分析不同设计对模型性能的贡献，并书写实验报告；
        
        难点在于\textit{实验设计}，代码修改的\textit{审美观}，以及\textit{结果分析}；这个可能适合作为 LAB1 的拓展内容；
        \item 给定一个任务，要求同学们可以参考一些参考资料中提到的一些方法，使模型的效果达到某个效果或以上；无脑选择所有优化手段并不能拿高分，在达成效果的前提下，需要同学们分析不同因素对最终结果的影响大小，能够选择较少的优化手段达成目标会有更高的分数；
        
        难点在于\textit{方法选择}的思考，以及\textit{结果分析}；这个可能适合作为中间某次实验的拓展内容；
    \end{itemize}
    \item \textbf{重「效果」的实验，增加指导，增设容错}：对于重效果的实验（比如本次 Final-Project 的 gobang 部分），建议在实验说明中给出一些\textit{常见问题的排查}指导，帮助同学们更快地定位问题，减少盲目试错的时间浪费；另外，建议增设一些\textit{容错机制}，比如在效果不理想时，可以分析\textit{失败机理}（比如 Mode Collapse 的分析）。
\end{itemize}
